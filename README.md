# Sopa de la Abuela

Juego de sopa de letras para aprender inglés. Buscás las palabras en la grilla y
la abuela te pregunta qué significan.

**Jugar:** https://gab26job.github.io/sopa-de-la-abuela/

Se instala en el teléfono y funciona sin conexión. Una sopa nueva por día, la
misma para todos: 8×8 para menores de 15, 10×10 con más inglés para el resto.

## Qué hay acá

Esto es solo el sitio publicado. Es un único archivo HTML sin backend, sin
cuentas y sin base de datos: todo el progreso vive en el teléfono de cada quien.

| | |
|---|---|
| `index.html` | el juego entero, con su vocabulario adentro |
| `manifest.webmanifest` | para que se instale como app |
| `sw.js` | para que abra sin conexión |
| `icono-*.png` | la abuela |

El código fuente, el corpus y las pruebas se trabajan aparte; acá solo llega el
resultado construido.
